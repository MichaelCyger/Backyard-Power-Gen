# US copyright registration (do this once)

The GitHub copy and the PDF already carry a copyright notice. That is not the same as a **registration**. Registration is what lets you sue in federal court for the text and collect statutory damages. The Copyright Office does it, not GitHub. Fee is **$45**.

I cannot finish the filing from here: it needs your login and a card. Use these fields.

## File

1. Open [Literary Works registration](https://www.copyright.gov/registration/literary-works/).
2. Start the **Single Application** ($45). Use this only because all of the following are true: one work, one author, you are the claimant, not made for hire.
3. If any of those is wrong, use the Standard Application ($65) instead.

## Form fields

| Field | Enter |
| --- | --- |
| Type of work | Literary Work |
| Title | Backyard Generating Station |
| Author | Michael Cyger |
| Citizenship / domicile | (yours) |
| Year of completion | 2026 |
| Claimant | Michael Cyger |
| Work made for hire | No |
| Publication | **Unpublished** while the GitHub repo is private. The short X post is not this book. If you later make the repo public, this unpublished registration still covers the text. |
| Limitation of claim | Leave blank unless you are excluding someone else’s figures |
| Deposit | Upload **`Backyard-1.3.pdf`** (the full book, current version) |
| Certificate email | michael@cyger.org |

Pay $45. Save the confirmation number and, when it arrives, the certificate PDF. Put the registration number in `README.md` under the copyright line, for example: `U.S. Copyright Registration No. TXu 2-___-___`.

After a later public version with substantial new text, file a new application for that version if you want the new pages covered the same way.
