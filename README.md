# Backyard Generating Station

**Version 1.4** (18 September 2026)

This is a book, posted as web pages. You do not need to know GitHub. Ignore the tabs at the top (Code, Issues, Pull requests) and any button that says Fork, Star, or Code. Those are for software. This is a document.

**This is a concept design basis.** It is not a DIY build, not construction drawings, and not a licensed nuclear plant, reactor, or appliance. No regulator has approved this design. Do not try to build it.

## How to read it

GitHub puts a list of files **above** this text. Scroll down past that list. You are in the right place.

Blue underlined text is a link. Click it. That is the only GitHub skill you need.

**The easy way: one file.** Open [Backyard-1.4.pdf](Backyard-1.4.pdf). If the page shows a preview, use **Download** (or the download icon) and open the file on your computer or phone. That is the whole book, in order.

**Or read it here, one chapter at a time.** Click a chapter below. On each chapter page you will see:

- a **Chapters** line at the top, so you can jump
- **Next** at the top and again at the bottom, which takes you to the following chapter

Start at [1. The Need](1_The-Need.md). Keep hitting Next until you run out of chapters.

If you ever land on a list of filenames instead of this page, click **README.md**. That brings you back here.
